Gestión de Reservas Turísticas

## Descripción
Herramienta digital para **centralizar y organizar reservas** de pequeños operadores turísticos, reduciendo cruces, pérdidas de información y problemas de coordinación.

## Usuario
Pequeños operadores turísticos que actualmente gestionan reservas mediante **WhatsApp, cuadernos y memoria**.

## MVP
- Registro de reservas y clientes
- Calendario de tours
- Asignación de guías y transporte
- Alertas de cruces de horarios
- Estado de reservas y cancelaciones
- Vista centralizada de próximas operaciones

## Objetivo
Permitir una gestión de reservas **más organizada y predecible**, reduciendo errores operativos y pérdidas económicas.
